## 📌 About the Event

**CRACK-UI** is a competitive frontend development event organized by **CyberCell BCET** as part of its annual flagship fest **CYBERVERSE 2K26**.

The event challenges participants to **replicate a given UI design** within a fixed time frame, testing their creativity, precision, and frontend development skills.

---

## 🎯 Objective

The goal of CRACK-UI is to:
- Enhance frontend development skills
- Promote design accuracy and attention to detail
- Encourage practical implementation using core web technologies
- Provide a fair competitive environment for students across all years

---

## 🧩 Challenge Format

- ⏳ **Duration:** 36 Hours  
- 💻 **Task:** Replicate the provided UI design as accurately as possible  
- 🛠 **Allowed Technologies:**
  - HTML
  - CSS
  - JavaScript  

- 🚫 **Restrictions:**
  - No external frameworks (like React, Bootstrap, Tailwind, etc.)
  - No pre-built templates

---

## ⚖️ Evaluation Criteria

Participants are judged based on:

- 🎨 UI/UX Accuracy (Pixel-perfect design)
- ⚡ Responsiveness
- 🧠 Code Quality & Structure
- 🚀 Creativity (if enhancements are allowed)
- ⏱ Timely Submission
